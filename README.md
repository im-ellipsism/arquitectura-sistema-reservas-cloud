# Sistema de Reservas en la Nube ☁️✈️

Este proyecto consiste en una arquitectura basada en microservicios para gestionar reservas de viajes, desplegada en AWS.

## 🚀 Tecnologías
- AWS (EC2, S3, RDS)
- Node.js / Python (microservicios)
- MongoDB / PostgreSQL
